# Mikolov et al. (2013): word2vec

A from-scratch NumPy rebuild of skip-gram with hierarchical softmax from
[Efficient Estimation of Word Representations in Vector Space](https://arxiv.org/abs/1301.3781),
trained on the first 2M words of [text8](http://mattmahoney.net/dc/textdata.html).

- [`word2vec.py`](word2vec.py): builds the vocabulary, training pairs and Huffman tree, then trains.
  Downloads text8 into `data/` on first run and saves `data/C.npy` and `data/vocab.txt`.
- [`eval.py`](eval.py): nearest neighbours and `b - a + c` analogies on the saved vectors.

```bash
python word2vec.py   # ~100 MB download on first run
python eval.py
```

`data/` is git-ignored; everything in it is regenerated by the scripts.
